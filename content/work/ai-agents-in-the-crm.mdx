## Context

Once a CRM holds real borrower data, giving an AI agent access to it is a security question before it's a product question. Each tool call has to be scoped to one tenant, permitted for the user behind it, and paid for.

I built the MCP server that exposes CRM operations as tools, the provider routing that lets the same tools work across three model vendors, and the metering that bills agent usage per call.

The full write-up (tool design, permission tiers, the billing migration) is being written now. It leads into my public project **mcp-tenant-tools**.
